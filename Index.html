All About Boba

What is it?

Boba, also known as bubble tea, is a popular Taiwanese tea-based drink invented in the 1980s. It typically combines freshly brewed tea, milk, and sweeteners, shaken with ice to create a frothy layer of bubbles on top.`

Types of Boba

Classic Milk Tea: Brewed black, green, or oolong tea mixed with milk and sweetener.

Fruit Tea: Refreshing iced tea infused with real fruit, syrups, or purees, usually served without milk.

Brown Sugar Milk: Fresh milk swirled with caramelized brown sugar syrup and warm tapioca pearls (often made without tea).

Taro or Matcha: Popular specialty drinks made with sweet purple taro root or earthy Japanese green tea powder.

Fun Facts

The "Bubbles" Weren't Originally the Pearls: The original name "bubble tea" came from the frothy foam layer of air bubbles created when shaking the tea with ice—not the tapioca pearls at the bottom.

Two Shops Claim to Have Invented It: Two Taiwanese tea houses, Chun Shui Tang in Taichung and Hanlin Tea Room in Tainan, both claim to have invented boba in the 1980s.

There Is a Word for the Texture: In Taiwan, the ideal bouncy, chewy texture of cooked tapioca pearls is described using the letter "Q" (derived from the Taiwanese Hokkien word khiū).

Pearls Have a Short Shelf Life: Freshly boiled tapioca pearls only stay soft and chewy for about four to six hours before they begin to harden, so shops make fresh batches throughout the day.

It Has Its Own Emoji: Boba became so globally popular that the bubble tea emoji was officially added to keyboards worldwide in 2020.

BobaDrops

Boba Drops is a beginner-friendly coding program run by Hack Club, a global nonprofit network of high school programming clubs. It is part of Hack Club's "You Ship, We Ship" (YSWS) series, which rewards teenagers for building and publishing real tech projects.

How It Works

Build a Website: Students learn the basics of web development by coding their own personal website from scratch using hand-written HTML and CSS. No prior coding experience is required.

Host It Online: Participants publish their code in a public repository and deploy the live website for free using GitHub Pages.

Get Boba: Once the website is reviewed and approved, Hack Club sends a $5 grant per approved site so the student (or club) can buy a real cup of boba.
